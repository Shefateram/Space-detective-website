# 🚀 Space Detective

**Space Detective** is an interactive storytelling website built with HTML, CSS, and JavaScript for the **NASA Space Apps Challenge**. 

## 🌌 About the Project
Somewhere among the stars, little machines have incredible stories to tell. **Space Detective** invites visitors to become space explorers and dive into the adventures, discoveries, and journeys of iconic spacecraft and rovers (such as NASA's Ingenuity Mars Helicopter).

## 🛠️ Built With
* **HTML5** – Page structure and storytelling layout
* **CSS3** – Custom styling, warm cosmic theme, and visual design
* **JavaScript** – Interactive elements and dynamic navigation

## 🚧 Project Status & Future Plans
This is a complete, functional prototype created as a hands-on web development learning project. While the core storytelling experience is live and complete for the hackathon submission, I plan to continue updating the site with new spacecraft "cases," animations, and features in the future.

## 🤖 AI & Learning Disclosure
This project was built as part of my journey learning front-end web development. AI tools were used to assist with understanding HTML, CSS, and JavaScript concepts, debugging code, and brainstorming story prompts.
